## 关键行为

- `cache_control` 白名单是防上游 422→400 的关键：任何非 ephemeral 的 `cache_control` 在 user 数组消息中被剥离（60），image 部分单独用 `pickEphemeralCacheControl`（56-57）。
- system 占位逻辑（136-140）：空 `systemPrompt` 时发送 `' '`，注释指出 token 由 7653 降至 85；可用配置关闭。
- `max_tokens` 上限强制 200000、默认 64000（128）。
- `forwardToCC` 不做重试与错误映射，非 2xx 由上层 `proxy-handler.callUpstream` 处理；`signal` 用于客户端断连级联取消。
