## forwardToCC 请求头

| 头 | 值 | 来源 |
|---|---|---|
| Content-Type | application/json | 固定 |
| Authorization | `Bearer ${apiKey}` | auth 提取结果 |
| x-cli-environment | production | 固定 |
| x-command-code-version | CC_VERSION | version 模块（动态） |
| x-session-id | getSessionId(...) | 透传或服务端会话 |
| x-co-flag / x-taste-learning | false | 固定关闭 |
| x-project-slug | fakeProjectSlug(sessionId) | util 确定性伪 slug |
| traceparent | generateTraceparent() | W3C 追踪头 |
| x-cmd-zdr | `1` | `CFG.zdr` 或请求头 `x-cmd-zdr:1` 时附加 |

## 设计说明

- `params.stream` 恒为 true：即使客户端要非流式，也以流式对接上游、由 proxy 聚合——统一超时与取消路径。
- `max_tokens` 上限 200000 硬裁剪，缺省 64000。
- AbortSignal 直接透传给 fetch，实现客户端断连 → 上游取消的级联。
